# 🌾 Wheat Phosphorus Use Efficiency (PUE) Transcriptome Analysis

## 📖 Overview

This project focuses on RNA-Seq based transcriptome analysis to identify genes associated with phosphorus use efficiency (PUE) in wheat.

The workflow includes quality control, read preprocessing, genome alignment, transcript quantification, differential gene expression analysis, functional enrichment, and visualization.

---

## 🎯 Objectives

- Identify differentially expressed genes (DEGs)
- Discover phosphorus-responsive pathways
- Perform GO and KEGG enrichment
- Visualize transcriptomic results
- Build reproducible RNA-Seq workflows

---

## 🛠 Tools Used

- FastQC
- Trimmomatic
- HISAT2
- Samtools
- StringTie
- featureCounts
- DESeq2
- R
- Python
